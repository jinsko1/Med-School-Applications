# School Major Contributions

Major contribution cards on each school dashboard come from `data/school_major_contributions.json`.

## Selection Rule
- Prefer a verified landmark discovery or Nobel-level contribution tied to the institution.
- If the medical school is new, use a strong affiliated research contribution only when the link is credible.
- If no credible landmark could be verified, keep the card explicit about that instead of inventing prestige.

## Caveat
Some entries are alumni, namesake, parent-university, or health-system contributions rather than discoveries made inside the current MD program. The `writer_note` field explains how cautiously to use each item in a secondary essay.
